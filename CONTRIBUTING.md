# Contributing to BrainBase

Thanks for your interest in contributing. Here's how you can help.

## Reporting bugs

Open a [GitHub Issue](https://github.com/noahsioo/brainbase/issues) with:
- What happened vs. what you expected
- Steps to reproduce
- Your OS, Node version, and AI provider

## Suggesting features

Open an issue with the `feature` label. Describe the problem you're solving, not just the solution you want.

## Pull requests

1. Fork the repo
2. Create a branch (`git checkout -b fix/your-fix`)
3. Make your changes
4. Run `npm run build` to verify it compiles
5. Commit with a clear message
6. Open a PR against `main`

Keep PRs focused — one fix or feature per PR.

## Code style

- TypeScript, strict mode
- No comments unless the logic isn't obvious
- Variable/function names in English
- Follow existing patterns in the codebase

## Security

Found a vulnerability? **Do not open a public issue.** See [SECURITY.md](SECURITY.md) instead.
